📌 Site Name

MoneyLens — Personal Budget Tracker
The name "MoneyLens" combines clarity and insight ("lens") with personal finance ("money"), suggesting a clear view of your spending, income, and savings. It's modern, memorable, and reflects the tool's core mission: helping users see their financial picture at a glance. Optional domain: moneylens.app or mybudgetlens.com (available for registration).

🎯 Site Purpose

The Personal Budget Tracker serves as an interactive and informational web application where users can manage daily finances. It provides a clean dashboard to log income/expense entries, categorize transactions (Food, Transport, Utilities, Entertainment, etc.), track real-time running balance, and visualize spending breakdown with dynamic charts/tables. The goal is to help individuals make smarter financial decisions, build saving habits, and understand spending patterns — all without page reloads, using modern HTML/CSS/JS.

❓ User Scenarios

  • "How much did I spend on eating out and groceries this month compared to my transport budget?" — The user expects to see category-specific totals and a visual pie/bar chart to compare spending habits.
  • "After adding my freelance income and medical bill, can I see my updated balance immediately without refreshing the page?" — Real-time updates and dynamic running balance are essential for the visitor's experience.

✨ Target audience: University students, young professionals, and anyone seeking a simple but powerful budget overview with instant feedback and interactive controls.

⚙️ Technical & Interactivity Summary

📄 HTML5 Structure

Semantic elements: header, main, sections, form, table or dynamic card container for transaction list. Accessible forms and ARIA labels for income/expense inputs.

🎨 CSS (Responsive)

Flexbox + Grid, mobile-first media queries, consistent spacing, and color scheme applied according to this plan. Buttons and cards adapt to different viewports.

⚡ JavaScript (Real-time)

Event listeners for adding income/expense, deleting entries, filtering categories. Dynamic running balance, total per category, and chart.js / custom chart update. No page reloads — using DOM manipulation and localStorage (optional for persistence).

Key interactive features: instant balance update, category spend breakdown, dynamic charts, validation for numeric inputs, and a summary table that updates as soon as user adds an entry. The project demonstrates full CRUD-like functionality for budget entries.

💡 Why this subject solves real needs?

Personal finance management is a daily necessity. This budget tracker gives users clarity, encourages responsibility, and provides visual feedback to adjust spending behavior. The interactivity (real-time, no reload) mimics modern web apps, making the experience frictionless. With my strong focus on UX and data representation, the tracker becomes a valuable tool beyond the classroom assignment.

Target audience scenarios covered: "How do I categorize an unexpected medical expense?" → dynamic category picker. "Show me the money left after all bills" → running balance always visible, plus chart forecasting. The site plan forms a solid roadmap to meet these demands.
